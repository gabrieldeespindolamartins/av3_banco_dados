Cardinalidades e regras

  • CIDADE 1:N ALUNO — uma cidade tem vários alunos; cada aluno aponta para no máximo uma cidade.
  • ALUNO N:N CURSO — resolvido pela entidade associativa MATRICULA.
  • PK composta em MATRICULA — o par (aluno, curso) identifica a matrícula e impede repetição.
  • Integridade sugerida: cidade excluída → SET NULL no aluno; aluno excluído → CASCADE nas matrículas; curso com matrícula → RESTRICT.
